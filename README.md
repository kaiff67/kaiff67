### &bull; Featured Production System

### &rarr; [Mini Loan Origination System (LOS)](https://github.com/kaiff67/mini-loan-origination-system)
*An end-to-end digital lending backend engine built in pure Java 17, raw JDBC, and MySQL 8.0.*

* **Automated Underwriting Engine:** Evaluates borrower creditworthiness, age criteria (21–60), and affordability limits (`FOIR <= 50.00%`).
* **High-Precision Financial Math:** Replaces binary floating-point primitives with `BigDecimal` (`HALF_UP`) to compute exact compound reducing-balance EMIs.
* **Atomic JDBC Transactions:** Enforces strict multi-table atomic updates across loan stages, disbursement ledgers, and audit logs with explicit rollback on SQL exceptions.
* **Asynchronous Automation:** Multithreaded background workers monitoring review aging SLA breaches and pushing disbursed records to Core Banking systems.
* **1-Click Verification Harness:** Built-in automated test suite programmatically executing and validating all 12 rubric evaluation scenarios in ~1.2s.
